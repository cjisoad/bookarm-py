# 安装与环境

推荐使用已经配置好的 `bookarm-beiyu` conda 环境：

```powershell
conda activate bookarm-beiyu
pip install -e .
```

如果需要重新创建环境：

```powershell
conda create -n bookarm-beiyu python=3.11
conda activate bookarm-beiyu
conda install pinocchio -c conda-forge -y
pip install -e .
```

项目依赖主要由 `setup.py` 和 ROS2 运行环境管理，核心包括：

```text
numpy
pin
opencv-python
open3d
pyserial
pyrealsense2
```

其中 `pin` 提供 Pinocchio 运动学库，`pyserial` 用于 ESP32 串口通信，`pyrealsense2` 和 `open3d` 用于 RealSense D435 采集与点云选点。

如果你要把项目接入系统 ROS2，请先看 [ROS2 运行指南](4.ros2_run_guide.md)。

## 运行位置

所有示例都建议从项目根目录运行。这样脚本可以正确找到：

```text
assets/bookarm_urdf/urdf/bookarm_urdf.urdf
calibration/camera_to_base.json
recordings/
```

## Windows 路径说明

项目路径里可以包含中文。为了避免 Pinocchio 在 Windows 下读取中文 URDF 路径失败，`BookArm` 会在内部把 URDF 复制到临时英文路径后加载，不需要手动移动 `assets` 目录。
