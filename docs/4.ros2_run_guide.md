# ROS2 运行指南

本文说明如何把当前项目作为 ROS2 `ament_python` 包运行。

## 前提

- Ubuntu 24.04
- ROS2 Jazzy 已安装
- 机械臂相关串口权限已配置
- `open3d`、`pyrealsense2`、`pinocchio` 等依赖已装到系统 Python `/usr/bin/python3`

## 关键约定

这个项目现在同时支持两种入口：

- 原始脚本入口：`python scripts/grasp/grasp_book.py`
- ROS2 入口：`ros2 run bookarm_control_py grasp_book`

ROS2 运行时请尽量使用系统 Python，不要让 conda 的 `python3` 抢在前面。

检查方法：

```bash
which python3
python3 --version
```

期望看到的是 `/usr/bin/python3`，而不是 conda 路径。

## 一次性准备

先进入 ROS2 环境：

```bash
source /opt/ros/jazzy/setup.bash
```

如果当前 shell 已激活 conda，先退出：

```bash
conda deactivate
```

确认系统 Python 依赖可用：

```bash
/usr/bin/python3 - <<'PY'
mods = ["numpy", "pinocchio", "cv2", "open3d", "serial", "pyrealsense2"]
for m in mods:
    try:
        __import__(m)
        print(m, "OK")
    except Exception as e:
        print(m, "FAIL", type(e).__name__, e)
PY
```

## 构建

在项目根目录执行：

```bash
colcon build --symlink-install --packages-select bookarm_control_py
source install/setup.bash
```

## 查看可执行入口

```bash
ros2 pkg executables bookarm_control_py
```

你应该能看到：

```text
bookarm_control_py grasp_book
```

## 运行

先看参数帮助：

```bash
ros2 run bookarm_control_py grasp_book --help
```

干跑模式：

```bash
ros2 run bookarm_control_py grasp_book --dry-run
```

真实执行：

```bash
ros2 run bookarm_control_py grasp_book --port /dev/bookarm --execute
```

如果你想跳过启动前确认：

```bash
ros2 run bookarm_control_py grasp_book --port /dev/bookarm --execute --yes
```

## Launch 启动

可以用 launch 文件启动：

```bash
ros2 launch bookarm_control_py grasp_book.launch.py
```

只查看 launch 参数：

```bash
ros2 launch bookarm_control_py grasp_book.launch.py --show-args
```

## 原脚本运行

如果你暂时还在 conda 环境里调试，也可以继续直接跑原脚本：

```bash
python scripts/grasp/grasp_book.py --dry-run
python scripts/grasp/grasp_book.py --port /dev/bookarm --execute
```

## 常见问题

### 1. `ros2 run` 找不到包

先确认已经执行过：

```bash
source install/setup.bash
```

再确认构建成功：

```bash
colcon build --symlink-install --packages-select bookarm_control_py
```

### 2. `import cv2` 或 `import pinocchio` 失败

这通常是系统 Python 依赖没装好，或者 `python3` 指向了 conda。

优先检查：

```bash
which python3
/usr/bin/python3 -c "import cv2, pinocchio"
```

### 3. `ros2 run` 启动后报串口错误

检查：

- 串口名是否正确
- 当前用户是否有串口权限
- ESP32 是否被别的程序占用

### 4. Open3D 窗口打不开

确认当前机器有图形桌面环境，并且 `open3d` 已装到系统 Python。

## 推荐工作流

1. `source /opt/ros/jazzy/setup.bash`
2. `conda deactivate`
3. `colcon build --symlink-install --packages-select bookarm_control_py`
4. `source install/setup.bash`
5. `ros2 run bookarm_control_py grasp_book --dry-run`
6. 需要真机时再加 `--execute`
